# Security Policy

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Report them privately through GitHub's
[Report a vulnerability](https://github.com/ainto-labs/ainto-app/security/advisories/new)
form (the **Security** tab → **Report a vulnerability**). This keeps the report
private until a fix is available.

Please include:

- A description of the vulnerability and its impact.
- Steps to reproduce, or a proof of concept.
- The affected version (see Ainto → Settings → About).

We aim to acknowledge reports within a few days and will keep you updated as we
work on a fix. Once resolved, we'll credit you in the release notes unless you
prefer to stay anonymous.

## Supported versions

Ainto is pre-1.0; only the latest release receives security fixes.
